# Kyle Bartlett

I spent more than 15 years in demand and supply planning at Sears, Belk, Apple and Anker, then started building the AI tools I wished I'd had. Now I run [Bartlett Labs](https://bartlettlabs.io), where I build AI agents and automations for operators and small businesses.

Most of what I build runs in production on my own servers. A few highlights:

| Project | What it is | Try it |
|---|---|---|
| [RepBot](https://github.com/kyle-bartlett/repbot-case-study) | AI receptionist that answers missed calls and books jobs for local service businesses. A product I sell, so this repo is a case study | [Site](https://repbot.bartlettlabs.io) |
| [Supply Radar](https://github.com/kyle-bartlett/supply-radar) | Supply chain risk dashboard you can question in plain English, with what-if scenarios drawn on the map | [Live demo](https://supply-radar.bartlettlabs.io) |
| [Weigh](https://github.com/kyle-bartlett/weigh) | Before/after eval harness for LLM pipelines: binary checks, cost per case, confidence intervals, a CI gate | [Live](https://weigh.bartlettlabs.io) |
| [PayGuard](https://github.com/kyle-bartlett/payguard) | Reads a pay stub with an LLM, then checks it against federal and state wage rules in plain code | [Live demo](https://payguard.bartlettlabs.io) |
| [agent-bus](https://github.com/kyle-bartlett/agent-bus) | MCP and REST message bus that lets my Claude Code agents and Grok bots message each other directly | |

**How I build:** TypeScript first, small services I can deploy and watch myself, and evals before I trust a model with anything that touches a customer.
